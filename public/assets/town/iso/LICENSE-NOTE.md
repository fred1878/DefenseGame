# Town isometric atlases: licence note

These atlases contain cut sprites from third-party itch.io packs (Antahonist terrain, SdavGha
"Pixel Worlds", Kyndrael castle sampler). See `CREDITS.md` at the repo root for authors, links and
licence terms.

- The SdavGha sprites are **AI-generated** (per the author); the Kyndrael sprites are AI-assisted.
- **Do not** extract these files and redistribute them as a standalone asset pack (raw or edited).
- **Do not** use these files to train or fine-tune AI/ML models or build datasets.

Rebuild with `python3 scripts/build-town-iso-assets.py <dir-with-the-original-packs>`.
